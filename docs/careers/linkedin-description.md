## Medium (recommended)

**ZUMIQ - Enterprise Data Intelligence Platform (Portfolio)**

Designed and built a cloud-native enterprise data platform that transforms raw
operational data into certified, governed, analytics-ready data products -
the way an internal platform team at a Fortune 100 company would build it.

**The problem:** In a large enterprise, teams suffer from duplicated data,
conflicting KPI definitions (7 versions of "revenue"), invisible data quality,
slow reports, and runaway cloud costs. Trust in "the numbers" collapses.

**What I built (on Google BigQuery):**
- A medallion data architecture (landing → raw → staging → core → gold →
  analytics) with SCD Type 2 dimensions and partitioned/clustered fact tables
- An automated Data Quality Engine scoring 9 dimensions with an enterprise DQ
  score (82 → 98), root-cause failure samples, and promotion-gated publishing
- A self-describing metadata platform: table/column catalog, ownership, SLAs,
  sensitivity classification (PII/PCI/PHI), column-level lineage
- Cost governance: per-query telemetry, team budgets, anomaly alerts, and a
  dry-run CI gate → 43% query-spend reduction
- A certified semantic layer + business glossary so every dashboard reads the
  same metric definitions
- 10 Tableau executive dashboards and 22 real enterprise incident playbooks

**Product thinking:** North-star metric (Weekly Trusted Decisions), guardrail
metrics, personas, PRD, roadmap, RICE prioritization, risk register, sprint
planning, and a metric-driven experiment loop.

**Artifacts:** 105 documented SQL queries, full BigQuery DDL/DML, Python DQ
engine + metadata agent + lineage parser, Tableau workbook, ERDs, data
dictionary, and an interview guide.

**Skills shown:** BigQuery, advanced SQL, data modeling (star/snowflake/SCD),
data governance, metadata management, data quality, Tableau, product
management, analytics engineering, cloud cost optimization, executive
reporting, stakeholder management.
